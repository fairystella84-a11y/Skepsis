# Skepsis

Ένας ιδιωτικός, ήρεμος χώρος όπου ο καθένας καταγράφει σκέψεις και συναισθήματα, βλέπει μοτίβα στον χρόνο και δουλεύει πάνω στον εαυτό του. Δωρεάν, σε ελληνικά και αγγλικά.

Οι πλήρεις προδιαγραφές είναι στο [docs/spec.md](docs/spec.md).

## Τι υπάρχει τώρα

Το πρώτο κομμάτι του MVP: μια PWA που δουλεύει εξ ολοκλήρου στη συσκευή (local-first), χωρίς server.

- **Onboarding:** καλωσόρισμα και δήλωση «δεν είναι θεραπεία», γλώσσα και θέμα, PIN, κλειδί ανάκτησης, πρώτο check-in.
- **Κρυπτογράφηση:** τίτλοι, κείμενα, απαντήσεις ασκήσεων και ονόματα tags κρυπτογραφούνται με AES-GCM (Web Crypto) πριν αποθηκευτούν στο IndexedDB. Το master key φυλάγεται τυλιγμένο με το PIN και με το κλειδί ανάκτησης (PBKDF2). Διάθεση και συναισθήματα μένουν αριθμοί και ids, ώστε τα στατιστικά να υπολογίζονται γρήγορα.
- **Κλείδωμα:** οθόνη PIN, αυτόματο κλείδωμα όταν η εφαρμογή μένει στο παρασκήνιο πάνω από ένα λεπτό, ανάκτηση με το κλειδί ανάκτησης, αλλαγή PIN.
- **Καταγραφή:** γρήγορο check-in 1–10, ελεύθερο κείμενο με αυτόματη αποθήκευση, καθοδηγούμενες ερωτήσεις ανά θέμα, ερώτηση της ημέρας.
- **Συναισθήματα:** λίστα σε δύο επίπεδα (οικογένεια → λεπτότερο), ένταση 1–10 ανά συναίσθημα, συνολική διάθεση.
- **Οργάνωση:** δικά σου tags, αναζήτηση, φίλτρα ανά tag και συναίσθημα, ημερολόγιο μήνα.
- **Ασκήσεις:** CBT thought record, ημερολόγιο ευγνωμοσύνης, αναπνοές (box και 4-7-8) με κινούμενο οδηγό.
- **Εικόνα μου:** γράφημα διάθεσης 30 / 90 ημερών, συχνότερα συναισθήματα.
- **SOS:** πάντα ορατό, γραμμές βοήθειας ανά χώρα, grounding 5-4-3-2-1. Ήπια ανίχνευση λέξεων κινδύνου μετά την αποθήκευση, που δεν μπλοκάρει και δεν ειδοποιεί κανέναν.
- **Δεδομένα:** εξαγωγή όλων σε JSON, οριστική διαγραφή όλων.
- Ελληνικά / αγγλικά, light / dark / αυτόματο, offline μέσω service worker.

## Τι λείπει από το MVP

Χρειάζονται server (PHP + MySQL) και αποφάσεις από τις «Ανοιχτές αποφάσεις» του spec:

- Λογαριασμός, συγχρονισμός και 2FA (TOTP). Οι εγγραφές έχουν ήδη `updated_at` / `deleted_at` για το sync.
- Face ID (WebAuthn).
- Γραμμές βοήθειας από τον server. **Οι αριθμοί στο `app/js/content.js` δεν έχουν επαληθευτεί** και πρέπει να ελεγχθούν πριν από οποιαδήποτε κυκλοφορία.
- Έλεγχος του περιεχομένου των ασκήσεων και των prompts από ψυχολόγο.

## Τοπική εκτέλεση

Χωρίς build και χωρίς dependencies. Αρκεί ένας static server στον φάκελο `app/`:

```sh
npx http-server app -p 8080
# ή
python3 -m http.server 8080 --directory app
```

και άνοιγμα στο http://localhost:8080. Το Web Crypto και ο service worker θέλουν `localhost` ή HTTPS.

Όταν αλλάζει οποιοδήποτε αρχείο της εφαρμογής, ανέβασε το `VERSION` στο `app/sw.js` ώστε οι εγκατεστημένες εφαρμογές να πάρουν τη νέα έκδοση.

    ui.js       DOM helpers
docs/
  spec.md     προδιαγραφές
