# Skepsis: προδιαγραφές

## Όραμα και αρχές

Ένας ιδιωτικός, ήρεμος χώρος όπου ο καθένας καταγράφει σκέψεις και
συναισθήματα, βλέπει μοτίβα στον χρόνο και δουλεύει πάνω στον εαυτό του.
Δωρεάν, σε ελληνικά και αγγλικά.

**Για ποιον:** ευρύ κοινό. Άνθρωποι που θέλουν να εκτονωθούν, να
γνωρίσουν τον εαυτό τους, να παρακολουθούν τη διάθεσή τους, να
επεξεργαστούν τραύματα του παρελθόντος ή να προετοιμαστούν για θεραπεία.

**Αρχές σχεδιασμού**

1.  **Ιδιωτικότητα πρώτα.** Τίποτα δεν μοιράζεται χωρίς ρητή ενέργεια
    του χρήστη.
2.  **Χωρίς πίεση.** Όχι streaks, όχι badges, όχι ενοχοποιητικές
    ειδοποιήσεις.
3.  **Ήρεμη, μινιμαλιστική αισθητική.** Απαλά χρώματα, πολύς λευκός
    χώρος, light και dark mode.
4.  **Παντού και πάντα.** Λειτουργεί πλήρως offline και συγχρονίζεται σε
    όλες τις συσκευές.
5.  **Δεν είναι θεραπεία.** Συμπληρώνει την επαγγελματική βοήθεια, δεν
    την αντικαθιστά, και το λέει καθαρά.

θα είναι προαιρετικό, με σαφή όρια και σύνδεση με το SOS.

## Οθόνες και ροή

Πέντε καρτέλες στο κάτω μενού, με ένα κεντρικό κουμπί «+» για νέα
καταχώρηση. Το SOS είναι πάντα ένα πάτημα μακριά.

**Πρώτη χρήση**

1.  Καλωσόρισμα: τι είναι και τι δεν είναι η εφαρμογή.
2.  Γλώσσα και θέμα (light / dark).
3.  Δημιουργία λογαριασμού, με επιλογή «συνέχεια χωρίς λογαριασμό».
4.  Ρύθμιση PIN / Face ID και, προαιρετικά, 2FA.
5.  Πρώτο check-in: «Πώς νιώθεις τώρα;»

**Κάτω μενού**

  -----------------------------------------------------------------------
  Καρτέλα                             Τι περιέχει
  ----------------------------------- -----------------------------------
  Αρχική                              Χαιρετισμός, γρήγορο check-in
                                      διάθεσης, prompt της ημέρας,
                                      τελευταίες καταχωρήσεις

  Ημερολόγιο                          Calendar view, λίστα καταχωρήσεων,
                                      αναζήτηση και φίλτρα ανά tag /
                                      συναίσθημα

  \+ Νέα                              Επιλογή: ελεύθερο κείμενο,
                                      καθοδηγούμενη καταχώρηση, άσκηση

  Ασκήσεις                            Βιβλιοθήκη ασκήσεων ανά κατηγορία:
                                      ηρεμία, σκέψεις, αυτοεξέλιξη,
                                      τραύματα

  Εικόνα μου                          Γραφήματα, συχνά συναισθήματα,
                                      μηνιαία ανασκόπηση, περιλήψεις AI
  -----------------------------------------------------------------------

**Ροή νέας καταχώρησης**

1.  Πώς νιώθεις; Επιλογή συναισθημάτων και έντασης 1--10.
2.  Τι συμβαίνει; Κείμενο ή απαντήσεις σε prompts.
3.  Tags (προαιρετικά).
4.  Αποθήκευση. Ήπιο μήνυμα, π.χ. «Ευχαριστώ που το κατέγραψες».

**Δευτερεύουσες οθόνες:** προβολή καταχώρησης, ρυθμίσεις (λογαριασμός,
ασφάλεια, γλώσσα, εξαγωγή, διαγραφή), οθόνη SOS, οθόνη κλειδώματος.

## Τεχνική αρχιτεκτονική

PWA που δουλεύει πρώτα τοπικά (local-first): όλα αποθηκεύονται στη
συσκευή και μετά συγχρονίζονται. Ο server βλέπει μόνο κρυπτογραφημένα
δεδομένα.

![Τα κείμενα κρυπτογραφούνται πριν φύγουν από τη
συσκευή](./media/architecture.png){width="5.833333333333333in"
height="2.763157261592301in"}

Τα κείμενα κρυπτογραφούνται πριν φύγουν από τη συσκευή

Η καταχώρηση κρυπτογραφείται στη συσκευή, αποθηκεύεται τοπικά και
στέλνεται στον server όταν υπάρχει σύνδεση. Το AI λαμβάνει κείμενο μόνο
όταν ο χρήστης το ενεργοποιήσει.

  -----------------------------------------------------------------------
  Κομμάτι                             Πρόταση
  ----------------------------------- -----------------------------------
  Frontend                            PWA σε HTML / CSS / JavaScript,
                                      εγκαθίσταται στην αρχική οθόνη
                                      κινητού και tablet

  Τοπική βάση                         IndexedDB μέσω Dexie.js

  Κρυπτογράφηση                       Web Crypto API (AES-GCM), κλειδί
                                      που παράγεται από τον κωδικό του
                                      χρήστη

  Backend                             PHP + MySQL στο Namecheap, όπως το
                                      FairyBeauty, με επιλογή datacenter
                                      στην ΕΕ

  2FA                                 TOTP, συμβατό με Google
                                      Authenticator, Microsoft
                                      Authenticator κ.λπ.

  AI                                  API γλωσσικού μοντέλου, καλείται
                                      από τον server μόνο με συγκατάθεση
  -----------------------------------------------------------------------

**Προσοχή στην κρυπτογράφηση:** αν ο χρήστης ξεχάσει τον κωδικό, τα
δεδομένα δεν ανακτώνται. Γι' αυτό στην εγγραφή δίνεται ένα κλειδί
ανάκτησης (recovery key) που ο χρήστης φυλάει.

## Μοντέλο δεδομένων

Εννέα βασικοί πίνακες. Τα πεδία με αστερίσκο (\*) κρυπτογραφούνται στη
συσκευή πριν φύγουν προς τον server, οπότε ο server αποθηκεύει μόνο
ακατανόητο κείμενο.

  -----------------------------------------------------------------------
  Πίνακας                             Βασικά πεδία
  ----------------------------------- -----------------------------------
  users                               id, email, γλώσσα, θέμα,
                                      2fa_enabled, encrypted_master_key,
                                      created_at

  entries                             id, user_id, type (free / guided /
                                      exercise / checkin), title\*,
                                      body\*, mood_score (1--10),
                                      created_at, updated_at, deleted_at

  emotions                            id, κλειδί, όνομα EL / EN,
                                      parent_id (για το επίπεδο
                                      λεπτότερου συναισθήματος),
                                      οικογένεια

  entry_emotions                      entry_id, emotion_id, intensity
                                      (1--10)

  tags                                id, user_id, name\*, χρώμα

  entry_tags                          entry_id, tag_id

  exercises                           id, κλειδί, κατηγορία, βήματα
                                      (JSON), μεταφράσεις EL / EN

  exercise_responses                  id, entry_id, exercise_id,
                                      answers\* (JSON)

  ai_insights                         id, user_id, period (week / month),
                                      summary\*, created_at
  -----------------------------------------------------------------------

**Για το sync:** κάθε εγγραφή έχει `updated_at` και `deleted_at` (soft
delete). Η συσκευή στέλνει ό,τι άλλαξε από τον τελευταίο συγχρονισμό και
κρατά την πιο πρόσφατη εκδοχή.

**Για τα στατιστικά:** η διάθεση και τα συναισθήματα μένουν ως αριθμοί
και ids, όχι κείμενο. Έτσι τα γραφήματα υπολογίζονται γρήγορα, και
τοπικά στη συσκευή.

## Ασφάλεια χρήστη και κρίση

Η εφαρμογή δέχεται καταχωρήσεις για τραύματα και δύσκολες στιγμές, άρα
χρειάζεται σχέδιο για την κρίση από την πρώτη έκδοση.

-   **Κουμπί SOS πάντα ορατό.** Ανοίγει οθόνη με γραμμές βοήθειας ανά
    χώρα (Κύπρος, Ελλάδα, διεθνείς), μία άσκηση grounding και ένα κουμπί
    κλήσης.
-   **Ήπια ανίχνευση.** Όταν μια καταχώρηση περιέχει λέξεις κινδύνου,
    εμφανίζεται ένα διακριτικό μήνυμα με το SOS. Δεν μπλοκάρει, δεν
    κάνει διάγνωση, δεν ειδοποιεί κανέναν.
-   **Επαφή εμπιστοσύνης (v2).** Ο χρήστης ορίζει, αν θέλει, ένα άτομο
    που καλεί με ένα πάτημα. Η εφαρμογή δεν το ειδοποιεί ποτέ αυτόματα.
-   **Προειδοποίηση στις ασκήσεις τραύματος.** Πριν ξεκινήσουν, ένα
    μήνυμα προτείνει να γίνονται με θεραπευτή αν είναι βαριές, και δίνει
    έξοδο ανά πάσα στιγμή.
-   **Καθαρή δήλωση.** Στο onboarding και στις ρυθμίσεις: η εφαρμογή δεν
    είναι ιατρική συσκευή ούτε υποκατάστατο θεραπείας.

Οι αριθμοί των γραμμών βοήθειας πρέπει να επαληθευτούν και να
ενημερώνονται από τον server, ώστε να διορθώνονται χωρίς νέα έκδοση.

**Νομικά (GDPR):** τα δεδομένα ψυχικής υγείας είναι ειδική κατηγορία.
Χρειάζονται ρητή συγκατάθεση, πολιτική απορρήτου, server στην ΕΕ,
εξαγωγή και οριστική διαγραφή με ένα πάτημα.

## Φάσεις υλοποίησης

Τρεις φάσεις, χωρίς πίεση χρόνου. Κάθε φάση τελειώνει με μια εφαρμογή
που δουλεύει και χρησιμοποιείς η ίδια πριν πας στην επόμενη.

1.  **MVP: ο πυρήνας**
    -   Λογαριασμός, PIN / Face ID, 2FA
    -   Ελεύθερη και καθοδηγούμενη καταχώρηση, γρήγορο check-in
    -   Συναισθήματα με ένταση, tags, αναζήτηση, ημερολόγιο
    -   Τρεις ασκήσεις: CBT thought record, ευγνωμοσύνη, αναπνοές
    -   Γράφημα διάθεσης, συχνά συναισθήματα
    -   Offline, sync, κρυπτογράφηση, SOS
    -   Ελληνικά / αγγλικά, light / dark, εξαγωγή και διαγραφή
    -   Κριτήριο ολοκλήρωσης: τη χρησιμοποιείς καθημερινά για 2
        εβδομάδες χωρίς προβλήματα
2.  **v2: βάθος και AI**
    -   Περιλήψεις και μοτίβα με AI (προαιρετικό, με συγκατάθεση)
    -   Σύνδεση tag ↔ διάθεσης, μηνιαία ανασκόπηση
    -   Φωνητικές σημειώσεις, body map
    -   Νέες ασκήσεις: γράμμα στον εαυτό, γνωστικές παγίδες, grounding,
        αξίες
    -   Εξαγωγή PDF για θεραπεία, επαφή εμπιστοσύνης, ήπιες υπενθυμίσεις
    -   Κριτήριο: μικρή ομάδα δοκιμαστών (beta) την έχει χρησιμοποιήσει
3.  **v3: τραύμα και αναστοχασμός**
    -   Ασκήσεις τραύματος (inner child), worry time, self-compassion
    -   Ήπιες ερωτήσεις αναστοχασμού από το AI
    -   Φωτογραφίες και σχέδια
    -   Δημόσια κυκλοφορία
